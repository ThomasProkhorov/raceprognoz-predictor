We’re building a lightweight F1 predictor app.

The app should let a user to see predictions of all predictors from [raceprognoz](https://raceprognoz.ru/formula1/) site and using live results via https://ocblacktop.com/api shows current standings of predictors with next pages:

- current stage predictions
- predictor standings
- live standings(according to live f1 race)

Keep the scope small: no auth, no database, no payments. Use Next.js, Tailwind, and shadcn/ui. For now, plan the architecture, components, routes, data flow, and implementation steps.
